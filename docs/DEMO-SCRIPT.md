# TankWar v1.0 · 演示视频脚本（≤ 2 分钟）

> T-27 交付物之二。本脚本为 v1.0 对外演示视频（≤ 2 分钟）的**分镜头拍摄脚本**，用于 PM 录屏、也可作旁白字幕底稿。已按"最少切场景 / 最多亮点"原则做过 4 稿裁剪，实际录制建议留 5–10s 缓冲。

---

## 0. 录制准备

**环境**：
- 浏览器：Chrome Latest，无痕窗口（避免扩展干扰）。
- 分辨率：1440×900 或以上，缩放 100%。
- 页面：先跑一次 `pnpm build && pnpm preview`，打开 <http://localhost:4173/> 而非 `pnpm dev`（避免 HMR 提示框入镜）。
- 音量：保持系统音量 30%，让 8-bit 音效清晰可闻但不刺耳。

**清理项**：
- 打开 DevTools → Application → Local Storage → 删除 `tankwar_leaderboard` 键（保证排行榜为空，方便演示破榜）。
- 静音关闭：如页面之前静过音，进入前按 `M` 恢复。

**工具**：
- macOS：`Cmd+Shift+5` 录制窗口 + 内录音频（用 BlackHole 或 Loopback）。
- Windows：OBS / ShareX，1080p60。
- 剪辑：iMovie / DaVinci / CapCut。**不加转场特效**，切镜用硬切，保留复古感。

## 3. 旁白剪辑要点

- **语速**：160 字/分钟左右，避免赶。
- **音效层次**：录制时游戏音效走系统内录；旁白后期贴在低音量层，游戏音在 -6 dB、旁白在 0 dB。
- **字幕**：全程双语可选。中文字幕用像素字体（VT323 / Zpix）呼应主题；英文字幕用同族像素英文字体。
- **BGM**：不建议叠加外部 BGM，8-bit 音效本身已是主角。
